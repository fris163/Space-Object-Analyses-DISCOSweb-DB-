This project pulls space object data from the DISCOSweb database, processes it, and plots it.

The goal was to find the average volume of each orbiting space object with a known mass,
in order to calculate how much "space" these objects actually take up in comparison to earth.

NASA images highly scale up space-object volume for demonstrations, and this leads to a misguided perception
that earth's orbit is extraordinarily polluted or "full." 

After getting the space object's average mass, it's possible to estimate the volume using this and 
average satellite densities. It is a rough estimate, because the average density is a partial assumption.

Then, the volume of an average object is attained, at 1.73 cubic meters. Multiplying this by the number of objects
gets up the total volume of space objects that orbit earth (which are tracked in DISCOSweb)

This is 36,615 cubic meters, or 0.00000000000000338% of Earth's total volume, or 546 shipping containers
